# Issue の書き方 — 早見表

**Issue は、AIへの指示書そのものです。** 人に頼むときに伝わる書き方は、AIに頼むときもそのまま伝わります。

---

## 型はこれだけ

```
【タイトル】 何を、どうしたいか

【現状】     いま、どうなっているか
【希望】     直したあと、どうなっていてほしいか
```

この2つが揃っていれば、そのままコピーしてAIに貼れます。

---

## いまいち / 良い

| いまいち | 良い | 何が違うか |
|:--|:--|:--|
| 修正お願いします | 定休日の記載が水曜になっているが、正しくは木曜 | **どこが・何が**間違っているかがある |
| 更新 | 営業時間を 11:00〜14:30 から 11:00〜15:00 に変更したい | **変更前と変更後**の両方がある |
| 色を直して | 各セクションの見出しを、ブランドカラー `#8b5a2b` に揃えたい | **具体的な値**がある |
| キャッチコピーがイマイチ | キャッチコピーを「毎朝打つ。それだけは、変えません。」に差し替えたい | **決定した内容**が書いてある |
| なんかおかしい | スマホで見たときにお品書きの価格が改行されてしまう | **いつ・どこで**起きるかがある |

---

## 3つのコツ

### ① 「なぜ」を1行だけ添える

```
定休日を水曜 → 木曜に変更したい
（10月から定休日が変わったため）
```

後から「この変更、何だったっけ？」を辿れます。AIが判断に迷ったときの手がかりにもなります。

### ② 決まっている値は、全部書く

「いい感じの色にして」は、人にもAIにも伝わりません。
`#8b5a2b` と書けば、一発で終わります。

### ③ 1つの Issue に1つのこと

「定休日と営業時間とキャッチコピーを直して」を1つの Issue にすると、

- 一部だけ終わったときに閉じられない
- AIがまとめて書き換えて、差分が読みづらくなる

**分けましょう。** Issue は何個作ってもタダです。

---

## やりがちな失敗

| ❌ | なぜダメか |
|:--|:--|
| タイトルだけ書いて本文が空 | 1週間後の自分が困る |
| スクショだけ貼る | 検索に引っかからない。テキストも添える |
| 「〜だと思います」で終わる | 決まっていないなら、決めてから Issue にする（または「要相談」ラベルを付ける） |
| 何でもかんでも1つの Issue に書く | 閉じられない Issue が育っていく |

---

## Issue を閉じるタイミング

**やることが終わったら閉じます。** Projects に載せてあれば、閉じた瞬間に自動で Done に移動します（設定不要）。

> 💡 迷ったら閉じてOK。再オープンもできます。
